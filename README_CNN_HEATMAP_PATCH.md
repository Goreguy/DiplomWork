# CNN Heatmap Patch

Патч делает два изменения:

1. CNN-карта теперь сохраняется как цветная тепловая карта NDVI, а не как серо-чёрное grayscale-изображение.
   - Низкие значения — красные оттенки.
   - Средние значения — жёлтые оттенки.
   - Высокие значения — зелёные оттенки.
   - Используется цветовая карта `RdYlGn`.

2. В интерфейсе Flutter изображение CNN NDVI-карты выводится в постоянном размере `420×280`, чтобы оно не растягивалось на весь экран.

## Какие файлы заменить

Скопировать файлы из папки `Diplom` в проект с заменой:

- `backend/services/ml_current_service.py`
- `backend/ml/predict.py`
- `lib/pages/analysis_result_page.dart`

## После замены

Перезапустить backend:

```bash
python -m uvicorn backend.main:app --reload
```

или тем способом, которым обычно запускается сервер.

Затем запустить приложение Flutter и снова выполнить анализ выбранного участка.
